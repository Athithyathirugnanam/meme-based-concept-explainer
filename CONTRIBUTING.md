# Contributing to Meme-Based Concept Explainer

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/meme-based-concept-explainer.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit your changes: `git commit -m "Add your commit message"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Create a Pull Request

## Development Workflow

1. Always work on a new branch, never directly on `main`
2. Keep your changes focused and atomic
3. Write clear commit messages
4. Test your changes before submitting
5. Update documentation as needed

## Code Style

- Follow existing code style in the project
- Use meaningful variable and function names
- Add comments for complex logic
- Keep functions small and focused

## Pull Request Guidelines

- Provide a clear description of what your PR does
- Reference any related issues
- Ensure all tests pass
- Update documentation if needed
- Be responsive to feedback

## Reporting Issues

- Use the GitHub Issues page
- Provide a clear description of the issue
- Include steps to reproduce if applicable
- Add relevant screenshots or error messages

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers and help them learn
- Focus on constructive feedback
- Collaborate openly

Thank you for contributing! 🎉
