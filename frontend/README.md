# Frontend

This directory contains the frontend application for the Meme-Based Concept Explainer.

## Structure

```
frontend/
├── src/           # Source code
├── public/        # Static assets
└── package.json   # Dependencies and scripts
```

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```
